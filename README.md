# Forge Pet 3D — Protótipo

## Como executar

Como o projeto usa módulos ES e importa o Three.js por CDN, abra-o através de um servidor local.

### Opção 1 — VS Code
1. Instale a extensão Live Server.
2. Abra a pasta do projeto.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.

### Opção 2 — Python
Na pasta do projeto, execute:

```bash
python -m http.server 5500
```

Depois acesse:

http://localhost:5500

## Recursos
- Cena 3D com Three.js.
- Coelho 3D construído com formas geométricas.
- Câmera giratória com mouse ou toque.
- Quarto 3D simples.
- Botões de alimentação, brincadeira, sono, banho e carinho.
- Barras de necessidades.
- Animações básicas.
