# Forge Palavras Ocultas — Protótipo

Jogo de caça-palavras responsivo para celular e PC.

## Recursos
- Grade 12x12
- Palavras em horizontal, vertical e diagonal
- Seleção por toque/mouse
- 3 temas que mudam conforme o nível
- Pontuação, moedas, tempo e níveis
- Dica por 10 moedas
- Salvamento com localStorage

## Executar
Pode abrir `index.html` diretamente no navegador, pois este protótipo não depende de bibliotecas externas.
